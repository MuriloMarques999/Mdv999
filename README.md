# Anime CRUD

## Descrição
Um aplicativo CRUD (Create, Read, Update, Delete) que permite gerenciar informações sobre animes. Ideal para praticar habilidades em desenvolvimento web e manipulação de dados.

## Funcionalidades
- Criar novos registros de animes.
- Visualizar a lista de animes cadastrados.
- Atualizar informações sobre um anime existente.
- Excluir registros de animes.

- **Back-end:** [Exemplo: Node.js, Express]
- **Banco de Dados:** [Exemplo: MongoDB, PostgreSQL]
